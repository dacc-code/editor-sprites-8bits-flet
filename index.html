Panel de Control — Hex Editor

Cada pixel = 1 bit. 8×8 = 64 bits = 16 hex. Clickeá los píxeles o carga un código.

Valor actual: 0000000000000000
Cómo usar:
• Click en un pixel: alterna APAGADO (gris #1e293b) ↔ ENCENDIDO (verde neón #22c55e) y actualiza el hex automáticamente (Dirección 1: Pantalla → Hex).
• Escribe hex (0-9, A-F, max 16) y presiona “Cargar Hex”: la matriz se pinta según los bits (Dirección 2: Hex → Pantalla).
• Ejemplos: 00FF00FF00FF00FF = rayas, FFFFFFFFFFFFFFFF = todo encendido, 0000000000000000 = todo apagado, 8000000000000000 = solo pixel (0,0).
